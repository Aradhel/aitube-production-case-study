# Open-Source Notices

AiTube combines original product engineering with open-source software and research implementations. The project does not claim authorship of third-party models or libraries.

The production release inventory must identify the exact repository, version or commit, model-weight source, license text, and download date for every deployed component. Publicly referenced components include:

| Component | Purpose | Upstream |
|---|---|---|
| MuseTalk | Audio-driven lip synchronization | https://github.com/TMElyralab/MuseTalk |
| SadTalker | Optional portrait/idle motion | https://github.com/OpenTalker/SadTalker |
| Kokoro | Text-to-speech option | https://github.com/hexgrad/kokoro |
| Chatterbox | Text-to-speech option | https://github.com/resemble-ai/chatterbox |
| rembg | Still-image background separation | https://github.com/danielgatis/rembg |
| Gradio | Interactive application UI | https://github.com/gradio-app/gradio |
| FastAPI | Production web/API layer | https://github.com/fastapi/fastapi |
| FFmpeg | Media inspection and encoding | https://ffmpeg.org/ |

Licenses can differ between source code, model weights, sample media, datasets, and pretrained checkpoints. An upstream repository license must not be assumed to cover every bundled asset. Third-party sample or test media must not be republished as AiTube product assets unless its license explicitly allows that use.

This case-study repository redistributes none of the listed projects, their model weights, or their sample media. The links above are provided for attribution and technical context.
