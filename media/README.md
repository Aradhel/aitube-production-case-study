# Approved Media

Only original, licensed, or explicitly authorized portfolio media belongs here.

Recommended files:

- `landing-page.webp` — clean public landing-page screenshot
- `creator-interface.png` — approved English production creator UI with account and usage statistics cropped out
- `transparent-export.webp` — editor timeline showing an authorized avatar overlay
- `demo-english.mp4` — short English product demonstration

Before adding media, follow the checklist in [PORTFOLIO_SCOPE.md](../PORTFOLIO_SCOPE.md). Video files are ignored by default; add a specific approved file intentionally only after review, or host larger demos externally and link them from the README.
